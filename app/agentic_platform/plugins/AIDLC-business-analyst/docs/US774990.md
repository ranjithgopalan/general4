## Technical Details

### Dependencies Auto-Installed

The skill auto-installs the following Python packages on first use:

```
python-docx>=0.8.11      # Word documents
openpyxl>=3.1.0          # Excel spreadsheets
weasyprint>=60.0         # PDF creation
pdfplumber>=0.10.0       # PDF extraction
markdown>=3.5            # Markdown processing
python-pptx>=0.6.21      # PowerPoint
extract-msg>=0.48.0      # Outlook MSG files
beautifulsoup4>=4.12.0   # HTML parsing
```

**Verified:** Auto-installation working correctly
- `openpyxl` installed on first XLSX use
- `python-pptx` installed on first PPTX use

### Conversion Methods Available

The `convert.py` script provides 18 conversion methods:

**Word Documents:**
- `md2docx` - Markdown to Word
- `docx2md` - Word to Markdown

**Excel:**
- `table2xlsx` - Markdown tables to Excel
- `xlsx2table` - Excel to Markdown tables
- `xlsx2csv` - Excel to CSV
- `csv2xlsx` - CSV to Excel
- `xlsx-sheets` - List all sheets
- `xlsx-info` - Sheet dimensions

**PDF:**
- `md2pdf` - Markdown to PDF
- `pdf2md` - PDF to Markdown

**PowerPoint:**
- `md2pptx` - Markdown to PowerPoint
- `pptx2md` - PowerPoint to Markdown

**Outlook:**
- `msg2md` - MSG to Markdown
- `msg2eml` - MSG to EML
- `msg-extract` - Extract attachments

**Additional:**
- Support for specific sheet extraction
- Support for cell range extraction (A1 notation)
- Support for multiple sheets

## Known Limitations

1. **PDF Generation on Windows:** Limited support due to weasyprint system dependencies
   - **Workaround:** Use MD→DOCX, then export to PDF from Word

2. **xlsx-info Command:** Minor bug with read-only worksheets
   - **Impact:** Low - extraction features all work correctly
   - **Status:** Non-blocking, can be fixed in future update

3. **Large Files:** PDF/DOCX extraction may timeout on files >50MB
   - **Mitigation:** Documented in README.md

4. **MSG Files:** Read-only support (cannot create MSG files)
   - **Expected:** MSG format is primarily for extraction
